# The World in One Day — Monday 23 November 2026

A broadsheet that sums up Monday 23 November 2026's world news in a single 1024×1024 image: Democrats take the US House with 258 seats, NATO meets in Brussels after Russian missiles fall in Poland, rescuers dig in Dymer — plus a six-number strip, a pinned world map, and the day in 30 stories, all drawn from Monday's reporting with named sources.

## How it was made

`draw.py` (Python + PIL, deterministic, no network) draws the broadsheet; `main.ts` (Node 22, standard library only) runs it and writes `entry.png` to `MAKEFUN_OUTPUT_DIR`. Two runs produce byte-identical output.
